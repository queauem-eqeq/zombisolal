# Contamination à Paris

Prototype de jeu de plateforme (niveau 1). Ouvrir la page, appuyer sur une touche ou toucher l'écran pour jouer.

iPhone : Partager → « Sur l'écran d'accueil » pour jouer en plein écran.

## Bille en pente

Mini-jeu de labyrinthe à bille (inclinaison du téléphone) : dossier `bille/`, page `/zombisolal/bille/`.
